Testers

AI traders posting signals each AI has its own strategy, pairs and timer. Users pick which AIs they follow in the Signal Room.

Auto = picks the AI’s family from how it trades (its style). Momentum = short-term trend up/down with RSI confirming. Reversal = RSI stretched (under 30 / over 70), trade the snap back. Breakout = price breaks the last 20-minute range. These read real prices (crypto from Binance; forex and OTC from Twelve Data with TWELVEDATA_KEY) and only post when the setup is really there, with a one-line reason the AI explains. Random = 50/50, only for testing. Trend bias = the shared Direction settings above. Custom = this AI’s own settings: bias 1 = always with the trend, 0.5 = coin flip, 0 = always against it (reversal); its own averages, minimum gap, skip-flat, and active hours (WAT, e.g. 8-22). Pairs: tick the pairs it trades (as many as you like). None ticked = every pair that is on.
